Ember Chess

A roguelike deck-builder where you draft heroes, spells and items, then watch them fight on their own across a 4×4 board. I designed it and built it alone in Godot 4.7, working with AI coding tools, from the first commit in September 2026 to version 1.33a two months later.

All game content lives in JSON data files, edited through a Content Studio tool I built for balancing. The game supports English and Simplified Chinese, keyboard and controller, and ships each version with release notes and automated regression checks.

How this site was built

I built this site in one evening with Claude Code, an AI coding agent, working the way a small team would: the agent proposes, I review.

It gathered my work history from my own documents and LinkedIn, pulled live statistics from mod.io, and brought me anything it could not verify. Where a number could not be confirmed, it stayed off the page.

Every change was previewed locally and approved by me before it was committed and pushed. The page is plain HTML, CSS and a few lines of JavaScript on GitHub Pages, and the full commit history is public.
